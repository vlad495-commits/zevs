# ЗЕВС — Сайт дезинфекционной компании

Корпоративный сайт компании **ЗЕВС** (дезинфекция, дезинсекция, дератизация).  
Стек: чистый HTML + CSS + JS, без фреймворков.

---

## Как развернуть

Это статический сайт. Достаточно загрузить все файлы на хостинг через FTP или панель управления Beget.

```bash
# Для локальной разработки — любой HTTP-сервер, например:
npx serve .
# или
python -m http.server 8080
```

---

## Лицензии и документы

Папка `docs/` содержит PDF-файлы лицензий компании — они отображаются на странице «Документы» главной страницы.  
Не удаляйте и не переименовывайте эти файлы без обновления путей в HTML.
